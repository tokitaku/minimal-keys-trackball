# minimal-keys 個人用ファームウェア

格子配列キーボード minimal-keys の個人用フォークです。キーマップとトラックボール設定をカスタマイズしています。

## フォーク元の取り込み

2026-10-17 に `hyhy-masa/minimal-keys-farmware` の `af465d9` まで取り込みました。
フォーク元はソースを削除してリリース配布専用に移行したため、このフォークでは削除直前の公開ソースを統合し、`config/`・`zephyr/`・ビルド設定を保持しています。非公開リポジトリの変更は含みません。

個人用キーマップ（エンコーダー割り当てを含む）、レイヤー4のポインター速度1/4、CPI 1600、XYスケール50、スクロールtick 24、デッドゾーン3/4、BLE接続間隔6/6は保持しています。フォーク元のBLEカーソル遅延対策、Studio RPCバッファ拡張、追加モジュール等を取り込んでいます。

## ビルド

`.github/workflows/build.yml` の GitHub Actions で左右のファームウェアと `settings_reset` をビルドします。リリース用manifest生成はフォーク元のワークフローを引き継いでいます。
