# レイヤー3のスクロール速度調整

## 目的

レイヤー3でトラックボールをスクロールに使用するとき、縦スクロールと横スクロールの速度を現在の約0.5倍にする。

## 現在の構成

- `config/boards/shields/minimal-keys/minimal-keys_R.overlay` の `scroll-layers = <3>` により、レイヤー3だけがPMW3610のスクロールモードになる。
- `config/boards/shields/minimal-keys/minimal-keys_R.conf` の `CONFIG_PMW3610_SCROLL_TICK=24` が、縦横共通のスクロール出力間隔を決めている。
- レイヤー4には、トラックボールのカーソル移動を0.25倍にする既存設定がある。

## 採用する設計

`CONFIG_PMW3610_SCROLL_TICK` を `24` から `48` に変更する。

PMW3610ドライバーは、X軸とY軸の移動量をそれぞれ蓄積し、絶対値がこの閾値を超えたときに横または縦のスクロールイベントを1回出力する。閾値を2倍にすることで、同程度のトラックボール移動に対するスクロールイベント数をおおむね半分にする。

スクロールイベントは離散値であり、1回のセンサー入力が複数tick進む場合もあるため、厳密な連続値としての0.5倍ではなく、体感上の約0.5倍とする。

## 変更範囲

- 変更するファイル:
  - `config/boards/shields/minimal-keys/minimal-keys_R.conf`
- 変更しないもの:
  - レイヤー3のキー割り当て
  - レイヤー4のカーソル操作と0.25倍設定
  - レイヤー5
  - `scroll-layers = <3>`
  - `ZMK_POINTING_DEFAULT_SCRL_VAL`
  - PMW3610ドライバー本体

## 期待する動作

- レイヤー3では、縦スクロールと横スクロールが現在より遅くなり、目安として約0.5倍になる。
- レイヤー3以外のカーソル移動速度は変わらない。
- レイヤー4の既存動作は変わらない。

## 検証

1. `CONFIG_PMW3610_SCROLL_TICK=48` が対象ファイルに1件だけ存在することを確認する。
2. `scroll-layers = <3>` とレイヤー4の `&zip_xy_scaler 1 4` が変更されていないことを確認する。
3. `git diff --check` が成功することを確認する。
4. ローカルで `west` を利用できない場合は、ファームウェアのコンパイル確認をGitHub Actionsに委ねる。
5. 実機でレイヤー3の縦横スクロールを操作し、変更前より遅くなっていることを確認する。

## 対象外

- 縦と横で異なる倍率を設定すること
- 押下中だけ速度を変えるキーの追加
- 実行中にスクロール速度を段階調整する機能
